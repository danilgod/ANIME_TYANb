# Альтушка-грязнулька

3D-игра про то, как отмыть и одеть альтушку. Персонаж — VRM-модель
(Sendagaya Shino, CC0-подобная лицензия VRoid), рендер на three.js.

## Маска для TikTok «Нефор-мейкап» — `mask.html`

Живой фильтр на фронтальную камеру: чёрные волосы, бледная кожа,
толстая подводка с длинным крылом и ресницами-шипами, тёмные брови,
розовые румяна, глянцевые губы, веснушки и пирсинг (snake bites).

- **Лицо** — 478 точек MediaPipe FaceLandmarker: макияж держится при
  повороте и наклоне головы.
- **Волосы и кожа** — MediaPipe Selfie Multiclass: волосы перекрашиваются
  в чёрный, лицо и тело светлеют, края масок сглаживаются.
- **На iPhone (рекомендуется):** открой
  <https://danilgod.github.io/ANIME_TYANb/mask.html> → «Включить камеру».
  Камера в Safari работает только по https, поэтому GitHub Pages — самый
  простой путь. Первая загрузка тяжёлая (~50 МБ моделей), дальше из кэша.
- **Без камеры:** кнопка «Посмотреть на фото» — макияж накладывается на
  `assets/demo-face.jpg` (демо-портрет, можно заменить своим).
- **До/после:** кнопка в правом верхнем углу, удерживай.
- **Запись для TikTok:** экранная запись iPhone, вертикальный кадр 9:16.

Модели лежат локально в `vendor/mediapipe/`, работают без CDN. Локальный
запуск: `Запустить игру.bat`, затем <http://localhost:8123/mask.html>
(на localhost камера тоже разрешена).

## Запуск

Двойной клик по `Запустить игру.bat`.

Он поднимает локальный сервер на `http://localhost:8123` и открывает
`altynka.html`. Из `file://` игра не работает: браузер запрещает странице
читать VRM-файл.

## Что внутри

- `altynka.html` — 3D-сцена: модель, перекраска волос и одежды, аксессуары,
  тату, поворот мышкой.
- `index.html` — 2D-версия игры (отмыть и одеть) на SVG.
- `v1-prototype.html` — первый прототип.
- `models/shino/` — VRM-модель.
- `three147.min.js`, `GLTFLoader.js`, `three-vrm.min.js` — движок локально.
- `serve.ps1`, `Запустить игру.bat` — локальный сервер.
